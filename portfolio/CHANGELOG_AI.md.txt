### Technical Decisions

Experience remains a separate content resource following the existing Projects/Skills architecture.

Experience supports:

- Company.
- Role.
- Period.
- Portuguese description.
- English description.
- Optional company URL.
- Publication state.
- Display order.

The existing PT/EN localization system is reused.

The existing SQLAlchemy metadata initialization convention is reused instead of introducing a dedicated migration for Experience.
