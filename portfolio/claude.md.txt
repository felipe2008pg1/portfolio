## Project Context

This repository is a personal portfolio application for Felipe Gonzalez, a Full Stack Developer.

The project contains:
- A public portfolio website.
- An authenticated administrative dashboard.
- A FastAPI backend.
- Database-backed Projects, Skills, and Experiences.
- PT/EN internationalization.
- Authentication and MFA-related administration.
