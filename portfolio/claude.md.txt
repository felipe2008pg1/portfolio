## What this project is

Personal full stack portfolio of Felipe Gonzalez (Full Stack developer, Python/JS/HTML/CSS, administrative/accounting background). Public website + authenticated admin panel for managing content (projects and skills) without needing to edit code.

## Stack

* **Backend:** FastAPI (Python), SQLAlchemy ORM, PostgreSQL (Neon, managed)
* **Frontend:** Vanilla HTML/CSS/JS — **no framework, no build step**. Everything is served statically.
* **Auth:** Short-lived access JWT + refresh token with rotation, optional MFA (TOTP), Argon2id for passwords
* **Deploy:** Backend on **Railway**, Frontend on **Vercel**, database on **Neon** (serverless Postgres)
* **Security:** Cloudflare Turnstile (captcha), rate limiting (slowapi), restrictive CORS, security headers

## How to run locally

Backend:

```powershell
cd portfolio/backend
.\venv\Scripts\Activate.ps1
uvicorn app.main:app --reload --reload-exclude "*.db" --reload-exclude "*.db-journal" --reload-exclude "*.db-wal" --reload-exclude "*.db-shm"
```

⚠️ `--reload-exclude` is mandatory — without it, uvicorn enters an infinite reload loop because SQLite/refresh tokens write to the database on every request, and the watcher interprets this as a code change.

Frontend: **VS Code Live Server**, serving the `frontend/` folder. Configuration in `.vscode/settings.json` (at the `portfolio/` root, not in `backend/`) restricts the watcher to `/frontend` and ignores `.db`/`backend/` — without this, Live Server reloads the page by itself every time the backend writes to the database.

## Known Gotchas (do not repeat these mistakes)

1. **Nested folder structure**: the user sometimes opens the terminal in the `portfolio site` folder (root on the PC), and sometimes in `portfolio site\portfolio` (repo root). This caused dozens of "path not found" errors. Always confirm with `pwd` before giving relative path instructions.
2. **`Set-Content -Encoding UTF8` in PowerShell adds a BOM** — this broke `vercel.json` (Vercel's JSON parser rejects BOM). Use `[System.IO.File]::WriteAllText($path, $content, (New-Object System.Text.UTF8Encoding($false)))` when encoding matters (JSON, YAML).
3. **SQLite does not preserve timezone** in `DateTime` columns — comparisons between `datetime.now(timezone.utc)` (aware) and values read from the database (naive) generate `TypeError`. There is an `ensure_aware_utc()` helper in `app/core/security.py` — always use it when comparing dates retrieved from the database.
4. **uvicorn `--reload` + database in the same monitored directory** = infinite restart loop. Always use `--reload-exclude` for `.db*` files.
5. **Cross-site cookies in production**: since the frontend (Vercel) and backend (Railway) are different domains, session cookies require `SameSite=None` + `Secure=True` in production (`ENVIRONMENT=production`), but `SameSite=Strict` in local development (same origin). This is already conditionally implemented in `_set_auth_cookies()` — do not revert to fixed `Strict`.
6. **Turnstile requires the exact hostname to be registered in the Cloudflare dashboard.** If local testing fails with "Security verification failed" or the widget does not load, first suspect: (a) test/real key mixed between frontend and backend, (b) hostname not registered, (c) accessing via `127.0.0.1` when only `localhost` was registered (or vice versa).
7. **Skill categories are entered in Portuguese in the database** (`Linguagens`, `Banco de Dados`, `Dados`, `Framework`, `API`, `Ferramentas`) — PT↔EN translation is automatic via `CATEGORY_TRANSLATIONS_EN` in `i18n.js`. If someone enters the category in English directly in the admin panel, translation breaks (it gets stuck, with no match in the map).
8. **Project images via external services (Imgur, LinkedIn CDN) frequently return 403** (hotlink protection). The adopted solution was to host images locally in `frontend/assets/img/projects/` and reference them via relative path (`assets/img/projects/name.png`). The backend validates `image_path`, accepting both full URLs (`http://`/`https://`) and relative paths starting with `assets/` (blocking path traversal).
9. **AI sandbox edits ≠ user's real repository.** During the 2026-08-25 session, an AI agent made a series of file edits (CSS/JS animations, an admin dashboard bug fix) inside its own sandboxed working copy of the repo, and only described the changes in prose in the chat instead of pasting the full code. The user reported the dashboard fix "still not working" — it wasn't broken, it simply had never been copied into the user's actual project. **Lesson: when working with a user who copy-pastes code manually (no shared filesystem/git access), always paste complete, copy-pasteable code for every change, not just a prose summary — otherwise assume nothing reached the real repository.** See `CHANGELOG_AI.md` Phase 10 for exactly which changes from that session are confirmed delivered vs. only designed.
