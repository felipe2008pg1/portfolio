## O que é este projeto

Portfólio pessoal full stack de Felipe Gonzalez (desenvolvedor Full Stack, Python/JS/HTML/CSS, background administrativo/contábil). Site público + painel administrativo autenticado para gerenciar conteúdo (projetos e skills) sem precisar editar código.

## Stack

- **Backend:** FastAPI (Python), SQLAlchemy ORM, PostgreSQL (Neon, gerenciado)
- **Frontend:** HTML/CSS/JS vanilla — **sem framework, sem build step**. Tudo servido estático.
- **Auth:** JWT de acesso curto + refresh token com rotation, MFA (TOTP) opcional, Argon2id para senha
- **Deploy:** Backend no **Railway**, Frontend no **Vercel**, banco no **Neon** (Postgres serverless)
- **Segurança:** Cloudflare Turnstile (captcha), rate limiting (slowapi), CORS restritivo, headers de segurança

## Como rodar localmente

Backend:
```powershell
cd portfolio/backend
.\venv\Scripts\Activate.ps1
uvicorn app.main:app --reload --reload-exclude "*.db" --reload-exclude "*.db-journal" --reload-exclude "*.db-wal" --reload-exclude "*.db-shm"
```
⚠️ O `--reload-exclude` é obrigatório — sem ele, o uvicorn entra em loop de reload infinito porque o SQLite/refresh tokens escrevem no banco a cada request, e o watcher interpreta isso como mudança de código.

Frontend: **Live Server** do VS Code, servindo a pasta `frontend/`. Configuração em `.vscode/settings.json` (na raiz `portfolio/`, não em `backend/`) restringe o watcher só pra `/frontend` e ignora `.db`/`backend/` — sem isso, o Live Server recarrega a página sozinha toda vez que o backend grava no banco.

## Gotchas conhecidos (não repita esses erros)

1. **Estrutura de pastas aninhada**: o usuário abre o terminal às vezes na pasta `site portfolio` (raiz no PC), às vezes em `site portfolio\portfolio` (raiz do repo). Causou dezenas de erros de "path not found". Sempre confirme com `pwd` antes de dar instruções de path relativo.
2. **`Set-Content -Encoding UTF8` no PowerShell adiciona BOM** — isso quebrou o `vercel.json` (JSON parser do Vercel rejeita BOM). Use `[System.IO.File]::WriteAllText($path, $content, (New-Object System.Text.UTF8Encoding $false))` quando o encoding importa (JSON, YAML).
3. **SQLite não preserva timezone** em colunas `DateTime` — comparações entre `datetime.now(timezone.utc)` (aware) e valores lidos do banco (naive) geram `TypeError`. Existe um helper `ensure_aware_utc()` em `app/core/security.py` — use-o sempre que comparar datas vindas do banco.
4. **uvicorn `--reload` + banco de dados no mesmo diretório monitorado** = loop de restart infinito. Sempre usar `--reload-exclude` para arquivos `.db*`.
5. **Cookies cross-site em produção**: como o frontend (Vercel) e o backend (Railway) são domínios diferentes, os cookies de sessão precisam de `SameSite=None` + `Secure=True` em produção (`ENVIRONMENT=production`), mas `SameSite=Strict` em desenvolvimento local (mesma origem). Isso já está implementado condicionalmente em `_set_auth_cookies()` — não reverta para `Strict` fixo.
6. **Turnstile exige hostname exato cadastrado no painel Cloudflare.** Se o teste local falhar com "Security verification failed" ou o widget não carregar, primeiro suspeite de: (a) chave de teste/real misturada entre frontend e backend, (b) hostname não cadastrado, (c) acessando via `127.0.0.1` quando só `localhost` foi cadastrado (ou vice-versa).
7. **Categorias de skill são digitadas em português no banco** (`Linguagens`, `Banco de Dados`, `Dados`, `Framework`, `API`, `Ferramentas`) — a tradução PT↔EN é automática via `CATEGORY_TRANSLATIONS_EN` em `i18n.js`. Se alguém digitar a categoria em inglês diretamente no admin, a tradução quebra (fica travada, sem correspondência no mapa).
8. **Imagens de projeto via serviços externos (Imgur, LinkedIn CDN) frequentemente retornam 403** (hotlink protection). A solução adotada foi hospedar as imagens localmente em `frontend/assets/img/projects/` e referenciar por caminho relativo (`assets/img/projects/nome.png`). O backend valida `image_path` aceitando tanto URL completa (`http://`/`https://`) quanto caminho relativo iniciando em `assets/` (bloqueando path traversal).
